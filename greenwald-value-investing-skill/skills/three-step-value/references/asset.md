# 资产再生产价值

## 经济判断

回答：按当前经济有效的方式取得企业现有同等经营能力需要多少成本，计入非经营资源，扣除义务和其他权益后，多少归母普通股。先选持续经营、清算或分部混合前提；单年亏损不自动清算，闲置能力不全算必需。金融、资源储量等特殊行业需重建行业口径，不能无说明强套本非金融模板。

先实际比较两年财报及关键附注，再看最新变动。把已做的两个年度比较保存到估值对象`annual_comparison`（文字、列表或对象均可），把实际阅读报告及章节保存到`materials_read`；这些字段记录已完成工作，不增加研究轮次或门槛。报告不会从别处零散叙述推断这些工作已做，也不能把未读章节填成已读。现金核总分和权属、限制及必要经营留存；财务公司存款若已含现金不能再加。应收从总额扣损失或从净额只调增量；存货区分正常数量与过剩可回收额。土地、建筑、装修、设备、使用权分别识别，权利与相关义务成对计量。在建工程说明按现状还是完工价值减剩余投入。

重大设施先看分类折旧、年限、残值、原值/累计折旧、减值及更新。把当前全新同功能成本调整到现有资源剩余服务能力；不从当前新价扣历史累计折旧金额，不把一年折旧当累计损耗。缺平均年龄可分类粗估；账面未折旧比例只是参照。已提足折旧仍在用不自动归零或还原全新。已含损耗的净估值不重复扣，装修受可执行租期/合理续租限制。

独立估计重大可再造的技术、获客、培训、组织与系统，可合理合并粗估。商誉以对应资源替换，品牌/渠道/客户、开发员工与系统只计一次。不可购买的集团身份/特许权不凭空给价；漏估资源后的EPV差额不能证明壁垒。联营投资持有权益与穿透资产不可双加。

全部正常、融资及表外经济义务进入一次；合同负债按履约或退款前提估，预收不自动归零；义务与相关可得资源配对。处置税仅在真实适用范围，不统一假想出售税。普通少数权益按对应子公司调整后净再生产价值与实际权利分配，不能一边用资产成本、一边扣永续利润倍数还称纯资产法；特别赎回/混合前提另说明。股息、新股与行权现金按同一事项配对。

## 完整可用的内部估值对象

参见合成`assets/asset-synthetic.json`。基本结构：

```json
{"method":"asset","currency":"CNY","valuation_date":"2026-06-30","shares":100000000,
 "premise":"持续经营；合成教学","summary":"结论及决定性假设",
 "items":[{"id":"cash","name":"现金","kind":"asset","operating":false,
   "book_value":100000000,"value":100000000,"basis":"fact","reason":"合成参数",
   "sources":["合成教学"],"include":true}],"assumptions":[]}
```

`items`每行：唯一`id`，`name`，`kind=asset|liability|nci|preferred`，`operating`布尔，`book_value`和`value`数字或null，`basis=fact|estimate|book|omitted`，`reason`，字符串`sources`，`include`默认true。可选`low/high`是各金额范围，不是联合经济情景；负值保留。`basis=book`且value为空时用book_value；`omitted`不计总值并说明影响。可选currency/unit须同估值币种且为基本单位。

跨方法引用可另记实际口径元数据：归母普通股范围明确时用`scope=parent_common`；`valuation_date`是估值基准日，`financial_position_date`是资产负债等财务存量的实际日期，两者不自动相同。`lease_basis`简述所选租赁计量口径，无租赁可写`none`，后续比较须一致。`scope_status`只有实际研究范围支持时才写`full`或`partial`，未确认保留`unknown`，不把研究结束自动升级为full；这些是口径说明，不是完成门槛或证书。成长复用时缺失元数据仍是未知，不能靠补标签伪造已核实的范围、日期或完整性。

父子项目以`parent_id`关联，一层计值，另一层`include=false`。采用子项时补估未拆余额；总额与明细不能累加。纯`value`估计足够。可选`formula`仅支持：

| method | 字段与运算 |
|---|---|
| quantity_cost | quantity×unit_cost |
| factor | base×factor |
| net | gross−deduction（缺省扣额0仅用于明确无扣额） |
| ownership | net_value×share |
| present_value | cashflows:[{amount,years}]，逐笔除以(1+rate)^years |

value存在时优先于formula。整额直接采用可用`fact_ref={"period_end":"2026-06-30","canonical_key":"cash"}`；只适用于唯一同期间、同币种、`unit=currency`的明确原额。拆分、比例、换汇或受限可回收估计不用整额引用。改为估计须移除fact_ref并写basis=estimate，否则程序仍使用原事实。引用失败会保留可用估计和说明，不把原事实改成估计。

联合情景：`scenarios=[{"name":"假设","reason":"原因","item_values":{"existing_id":完整替换金额},"shares":可选正数}]`，只改既有入选项目和股数，币种不变；资源与义务变化配对。纯范围/文字只是讨论，不能声称程序已算联合总值。

## 结果与复核

归母价值＝入选资产−负债−少数权益−优先权益；每股＝归母价值/同权在外股数。说明已计量范围、重大未计量及估计敏感性；缺少重要义务不能称已验证下限。可用`reproduction_context`简述业务范围、复制成本/时间、取得限制供后续复用，这不自动证明持续优势。估值完成后再加入股票报价比较；不为现价调资产参数。
