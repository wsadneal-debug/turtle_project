# 宿主研究、复核与报告

## 轻量完成记录

每个方法保留`input.json`、`valuation.json`、实际计算与`report.md`；宿主可用一个`stages.json`记录`materials/plan/research/synthesis/calculation/review/final`的pending/completed/skipped及一句说明，格式不强制。已有材料足够时研究阶段可直接由宿主完成；只有实际派过原生子代理才记录真实代理答复，只有实际调用外部研究模型才记录真实调用。无须伪造calls目录、token账、证明或证书。

计划按决定性问题分工；专项交实际事实、估计、推导及反证，宿主综合采纳/修改/拒绝理由，不平均互不兼容结论。Python初算后复核经济范围、重大遗漏、币种、单位、算术和重复计价；更改最终参数再实际重算。工具失败如实保留，用其他可用来源或合理假设继续；不因小缺口统一追加轮次。成长investigate仅一个适用性疑点查一次后收敛，不重复循环。

宿主允许且原生子代理可用时，主模型按复杂度选择可独立回答的有界专项，例如最新事实、资金及对应义务、维护投入或关键假设复核；提供相关原文与口径，不灌入预期结论，也不让每个子代理重做整套三法。主模型负责采纳、去重、口径协调和最终计算；不强制数量、轮数或付费CLI，无此能力时自行完成。

经济复核回到关键原文确认正负号、单位及总额与子项关系，不只重算已填参数。披露的原始事实与正常化采用的假设分开说明；若选择不同于报告期实际数的正常负担，解释估计理由即可。

集中实质复核少数会改变结论的假设：其依据是否承认最新相关事实、经济解释是否成立、最终实际参数是否与解释一致。按方法选重点，如受限资源释放与对应义务、维护口径、集团增长映射及投入；发现偏差再修正并重算，不用“保守”或文字已提及代替核对，也不扩成逐项门禁或强制重研。

研究中断就保留已完成结果及尚未执行阶段，不自动把准备成功当研究完成。旧完成研究重新算参数不产生新阅读/复核，skip/defer重算也不自动变evaluate。没有Python执行能力时交付估值参数与研究说明并写“未执行计算”，不能凭头算或输出JSON称程序验算通过。

## 报告读法

前部用通俗中文一小段说明本次结论、决定性原因和主要约束，金额用亿/万等易读单位并标币种；精度在台账保留。然后展示当前方法必要的计算桥：

- 资产：选定前提、经营资源/非经营资源、负债、少数/优先、归母及每股；区分全新成本与现有净值。
- EPV：正常EBIT→可分配盈利；核心EPV→归母股权；列实际维护、税与资本成本依据。
- 成长evaluate：明确优势与增长范围、全部股权买价Q/净调整B/核心买价M、D/I/A资金账、三项回报、衰减处理、资本成本差额与有效情景；不能把D/M称个人股息率。
- 成长skip/defer：只说适用性、主要依据/反证、前两模块参照和后续影响，不堆空数表。

把公司披露/实际数据、行业惯例、自主估计、用户指定政策和程序结果分开。列实际使用报告、关键页/章节与URL/文件，说明哪些全文已准备、哪些实际阅读、哪些工具失效/材料未齐；不列未读章节冒充覆盖。来源冲突、重大上游未明事项及反证保留，不用“保守”掩盖已知重复扣减。

日期分别为估值日、研究/证据截止日、股权桥财务存量日、报价日及汇率日；缺日期写未单列，不能从截止日倒推更新已完成。至少比较两个完整年度，EPV另说明采用的长期序列及周期局限。报价/换汇来源未独立核实就不要称认证行情。

三方法可以并列解释资源复制、正常盈利与新增投资的关系；没有一致日期、范围、币种、租赁和完整性时不报精确差额。资产与EPV不相加，成长回报不转成成长总价。资产价值不是清算保证，EPV不是价格底线，条件回报不是实际IRR；算术算成、研究完成、方法适用、符合用户回报要求与买入决策分别说明。

用情景呈现决定性估计的影响，不取不兼容情景的平均数，不把敏感性范围叫概率置信区间。数值未知与经济上不存在分开；量化衰减没做就标衰减前，定性分析仍可给有理由的条件判断，不能称风险调整后净回报已验证。

用户要求三步完整研究时，最终另写一份`combined_summary.md`作为主要阅读交付，从三个已保存的最终计算与方法结论综合：资源值、正常盈利值、成长适用性与本价回报、关键分歧及共同风险；保留各方法独立report.md和台账链接，不把它们再算一个总价值。只要求单方法时不强制汇总稿。
