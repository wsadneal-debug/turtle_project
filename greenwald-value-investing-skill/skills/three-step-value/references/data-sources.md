# 资料发现与只读适配

## 先确认可用能力

发现本环境已提供或可搜索的金融数据、联网、文档、云盘MCP工具，优先尝试相关查询，核对实际响应。已有数据工具能补报表、股数或历史序列时利用它；报告全文仍优先上市公司投资者关系、交易所披露或法定公告网站。工具不可用、无权限、有限额或无所需字段时记录原因，换上传资料或官方公开来源；不把连接器作为安装前提，不自动开通收费、装软件、改授权或填凭据。

用户尚未说明时按SKILL入口只问一次是否有自建数据库、数据文件或财报目录。不要求用户建立与本包相同的库。答复给出路径才检查该范围；已有明确上传/路径就直接用。先列所给目录的文件或读取数据库schema，再限定公司和期间查询；不遍历主目录、其他项目或未指定的私人来源。

## 对接任何原始来源

- SQLite用只读URI `file:/所给路径/db.sqlite?mode=ro`，并设 `PRAGMA query_only=ON`。其他数据库使用只读账户/事务和有界查询；不做迁移、更新、建表或源数据修复。
- CSV/JSON/Excel先看列名、期间、范围、原单位、币种和来源说明，再读取所需行；只有匹配报表口径的字段才映射。没有固定表名、字段名或供应商要求。
- PDF优先可读文本层，可用已有PDF工具或`pdftotext -layout`生成本轮文本副本；图像扫描可用环境已有OCR并抽查关键页。工具缺失时请求可读上传或换官方文本版本；不谎称抽取成功。
- 报表要核对主体及合并/母公司范围、完整年度/累计/单季、会计准则、修订和重述。收入与现金流等流量不与资产存量混用；中报不直接乘二。

把原始名称、原始数值、原始单位和来源保留在packet事实中，归一金额另记`value`。按原表头辨认损失/转回方向，不能只看数字符号或科目名称。`unit=currency`表示已经是币种基本单位，不能再乘千/百万。空值不是零；来源冲突需写明选择和原因，不用不同供应商无条件补全。提供给计算器的是[内部packet](runtime.md)，这是宿主AI在阅读后生成的中间件，**不是对用户原库的schema要求**。

重大现金、存款、金融资产和债务沿附注拆分必要类别，核对现金等价物、期限、限制及总分重叠，不能把报表汇总行当成全部明细。未拆小项可按重大性合并或估计，简述依据即可。

## 报告与长期数据

最近两个已披露完整财年的年报全文和附注都要准备，另取其后最新季报；当地不披露季报时取中报。年报内的上年比较列不替代第二份完整年报。非自然年结按实际财年；保存报告期、公告日、URL/用户文件与本轮可读文本路径。

实际比较两年业务、财务及关键附注；最新一期更新变化。可按目录、检索和连续章节定位有关内容，不要求逐字读无关章节，不能把截断输出或摘要说成全文已读。缺件时继续定向找官方原文，仍缺则明确披露材料未齐，可作有据条件估计，不称已满足完整材料要求。`materials_ready`只说明文件准备，不证明经济研究完成。

涉及重大税收认定、权利限制、合同或经营状态时，在同一主体、同一事项与可比期间内采用更新披露的事实，说明对旧依据的更新；不把最新一期所有数字机械替代历史正常化资料。最新事实与未来假设分开：可以保守估计未来税负、续期或增长，但须承认已披露的新事实，并解释为何未来采用不同水平，不能继续用已过时的认定或期限作理由。

EPV优先使用已存在的可比长期序列判断正常利润率与周期位置；不强制10年/20年或为了凑年数全量抓取。短历史/结构变化可估计并说明局限。TTM只在年度、本期累计与上年同累计同币种同范围时用“年度＋本期−上年同期”，只是算术参照，不等于正常盈利。

价格与汇率保存实际取得的日期、方向和出处。A/H同一集团只估一次，使用全部同权在外普通股；加权平均EPS股数不自动适合作每股价值分母。单一每股报价乘全部股数是统一价格假设，不能冒称A/H实际总市值。换汇缺失仅影响报价比较，不把缺价当零。先独立研究资产/EPV，再作股票价格比较，避免按现价倒推价值。
