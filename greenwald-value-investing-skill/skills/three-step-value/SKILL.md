# 三步价值研究

宿主AI负责取数、读报告、提出假设、综合与复核；随包Python负责算术和报告。默认按资产→EPV→成长运行，也尊重用户只做某一步、复用已选EPV或只改价格重算的要求。三个结果独立，不相加、不平均；成长是回报评价，不是另一个应与前两者相加的价值总额。

## 从资料开始

1. 明确企业、方法、估值日、计价币种和已有研究。**先发现并尝试本环境相关的MCP/金融数据/报告工具**；有多个渠道时选择可用且适合的，不要求特定供应商、表名或凭据。仅看工具名称不算取得数据，实际返回的来源、期间、单位和范围仍须核对。没有连接器也能用上传文件和公开官方报告。
2. 如上下文尚未说明本地来源，**一次询问**：“你是否已有可只读使用的自建数据库、数据文件或财报目录？若有，请给路径/文件；若没有，我会使用可用工具和官方报告。”在答复前可继续工具发现和官方来源检索；不要重复询问已知来源，也不要扫描用户主目录或猜私人路径。
3. 按[资料与适配](references/data-sources.md)有界读取用户明确提供的来源，准备最近两个完整财年的年报全文及附注、之后最新季报或中报；缺件定向找官方报告。AI从实际原文/数据写内部packet；Python不会从PDF自动识别财务事实。缺失事实保留null，估计放估值层。

## 研究和计算

按需读相关方法，不必加载全部引用：

- [资产法](references/asset.md)：当前同功能经营资源的经济净再生产价值、非经营资源及全部义务。
- [EPV](references/epv.md)：当前规模的正常可分配盈利、维护、税、资本成本及归母桥；先独立估算，再解释与具名资产研究的差异。
- [成长](references/growth.md)：先判断持续竞争优势及增长边界，选择evaluate/skip/investigate/defer；只对适用范围计算给定价格的回报。必须考虑经济衰减，半衰期数字可选。

允许并鼓励惯例、类比、经验比例和合理自主估计，尽量交付资产/EPV基准；小项可沿用账面、粗估、合并或明确略去。按经济重大性决定补查，不设统一比例、历史年限、评分或完整性证书。两年财报期不等于两个经济周期。

每个模块用独立新目录。用轻量阶段记录保留实际完成的资料准备、计划、必要专项、综合、Python初算、复核与最终重算；资料已有答案时直接复用。宿主允许且原生子代理可用时，主模型按复杂度把独立问题拆成有界专项，见[报告与复核](references/delivery.md)；没有此能力时自行完成，不依赖外部模型CLI、特定模型或付费API，不强制代理数量或研究轮数。不为填字段循环研究。阶段未执行写skipped/pending，不伪造代理调用、阅读或复核。

按[运行与内部packet](references/runtime.md)调用随包`scripts/run.py`，资产/EPV/growth参数合同分别在上述引用中。先确认Python 3.10+及本地文件读写可用；不要求安装包、改系统配置或导入凭据。执行不了时仍可研究和交付结构化参数，但必须说未实际执行/未核验数值。示例全为合成教学输入，不能当真实公司事实。

## 交付

按[报告与复核](references/delivery.md)用通俗中文先说结论、决定性原因和可能改判的条件，再给计算桥、来源与估计。报告分别说明资料是否齐备、研究做了哪些、程序是否实际执行、方法是否适用、价格是否支持条件回报。完成研究或算术不等于批准买入；资产/EPV也不是保证底价。用户没有请求批量筛选、定时、交易或发布时，不增加这些流程。
