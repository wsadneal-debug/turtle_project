# 龟龟企业研究 V5.2.2

先判断经营，再判断价格。基本面稳定、不实质衰退和分红可持续是前提；现金回本与穿透回报必须各自成立，不能互相补偿。低价不抵销重大经营或诚信问题。这里是可移植的方法包，不是生产研究系统。


当前现金回本默认采用正常化历史平均＋经营变化调整，直接使用六年归母现金并保留负值；首次分析识别最新重大资本项目及付款阶段。详见[现金回本](references/absolute-valuation.md)，旧公式只作明确标注的兼容参考。


## 开始与可选尽调
确认企业、证券权益、研究截止日和公开/附件/离线范围。普通分析的额外尽调默认关闭，开始时简短询问：“本次是否启用额外投资尽调？默认不启用；启用后会增加重大风险、独立估值和交易条件核查，需要更多时间和模型额度。”等待期间继续基础分析；未回复、拒绝或只要求普通分析，均不启动尽调，也不阻断基础报告。
用户在本次任务已明确要求尽调时不重复询问。确认启用后使用同包可单独安装的 `turtle-due-diligence`，读取其入口及实际需要的参考；未安装时说明缺失，不能声称已完成尽调。不因安装两个Skill、价格通过、风险较高或缺数据而自动启动。未启用时不加载十方向题库。

## 六加一研究流程
1. **核查和定题。** 先核对原始现金、分红及有效回报安排，保留纠正前后值、正式来源、期限及实际核查日，再初算。普通人工指定研究不受资源初筛限制；批量候选才按[研究分流](references/research-routing.md)应用两项各65%的资源线，不能当买入资格。
2. **赚钱与保护、自然趋势。** 找主要利润池、客户和收费机制；用五年及最新单季/可比半年辨认季节性、周期和结构变化。壁垒不等于需求稳定，未找到下降证据不等于六年平坦。
3. **可信抵补、自我供血。** 重大事件推演未来量价与兑现时间，按集团利润/现金口径缩放，扣必要投入；检验不增加净外部资金时能否承担运营、必要资本开支、到期义务和分红。未来成功转型不算现有保护。
4. **原有股东结果、最强反论。** 查现金真实性、归属和可上划性、资本纪律、净稀释及分红兑现；比较最强替代解释。仅对决定性缺口安排有界调查，完整保留所得依据和集团量级。六问是因果主线，不是六个固定代理或评分章节。
5. **综合经营。** 在看报价前选择最可能的基准：判断期间（默认六年）、稳定/改善/衰退、衰退是否主观上更可能、小幅/大幅、核心因果、分红后果及一项主要反转条件。普通缺数不代替结论；确无依据或工具失败则如实保留未完成。详见[分析](references/analysis.md)。
6. **程序计算。** 按同一最终现金假设计算原双价格、实际现金路径及两项容错。六年路径与经营基准一致；仅旧兼容路径在幅度未知时保留null及不增长参考上界，不由分档生成跌幅。读[现金回本](references/absolute-valuation.md)、[穿透回报](references/lookthrough-return.md)、[容错](references/headroom.md)。可用宿主计算器或包内[零模型脚本](references/calculator.md)。
7. **现价安全垫裁决。** 读取现金组成、实际路径、回报组成、期限和容错，判断主要风险怎样消耗已有保护。双达标不代替安全垫解释，停止增长不等于已扣衰退；按取舍后的假设重算，再独立给价格及策略资格。

## 宿主能力与历史
单一模型可在当前会话顺序完成定题、取证、综合和裁决；这是单模型研究，不冒称多模型独立验证。只有宿主具备且用户授权时才派有限子代理，先约定预算；同轮输入核查、主模型、子代理和复核使用同一provider，多渠道对照另起独立研究；仅派决定性缺口，不递归、不投票、不为了填角色耗尽额度。停止/额度不足保存已有结果，不自动换模型、扩额或整轮重跑，不用模型反复轮询进度。

无需私有数据库、固定模型、API密钥、付费数据或第二个Skill即可完成基础分析。Python只用于可选计算，不负责联网或调用模型。没有浏览能力用附件；没有计算能力给算式并标未执行；缺五年、行业库或精确字段只限制依赖项，不填零、不伪称标准价格通过。只用已授权工具，不安装服务、不上传私有资料、不执行交易。

历史模型结论仅继承同来源模型渠道、方法5.2.2及以后、截止日前365天内最近一份精简结论；来源不明、旧版、跨渠道或超期时重新读原始事实，不沿用其模型解释。没有历史/行业记忆正常开工。原始公共事实可共享；行情刷新零模型，不改原研究日期/方法、不自动更新事件判断。输出到用户任务目录，旧报告保留；语言服从用户要求。
