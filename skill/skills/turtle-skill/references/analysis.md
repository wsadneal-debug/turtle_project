# 分析：把事实推到集团和股东结果
用于主线第1—6步；不重复取数、价格公式或安装说明。

## 五年、最新单季与季节性
五年观察目标包括营收、归母利润、经营现金、资本开支、FCF、股数及每股分配；用可比披露构建趋势，必要时扩展至周期低谷。资料不满五年继续研究并说明缺口，不补造，也不把短历史称跨周期证据。

核对同一主体、币种、量级、会计定义及合并范围后，仅对累计期间流量拆分：
```text
Q2 = H1 - Q1
Q3 = 9M - H1
Q4 = FY - 9M
H2 = FY - H1
QoQ_pct = (Q_latest / Q_previous - 1) * 100
YoY_pct = (Q_latest / Q_same_quarter_prior_year - 1) * 100
HoH_pct = (H_latest / H_previous - 1) * 100
```
环比跨年时用上一年Q4或H2；非日历财年按真实起止日。上述百分比仅在基数为正且有解释力时使用；零、负或接近零基数展示原值、绝对变化及盈亏转换，不制造失真增长率。现金、债务、应收、存货等余额不这样相减。

两类环比均检查行业季节性、节庆、天气、促销与交付验收节奏，参照过去两三年同季/同半年及直接同行；正常淡旺季允许大幅变化，但也不能泛称季节性掩盖恶化。区分普通减速、实质失速、绝对下降和结构性衰退，降幅收窄不等于恢复增长；H1正增长不能覆盖Q2反转。

程序无法可靠提供时自行读正式披露拆分，注明模型计算；缺Q1不得用H1除二虚构Q2。季度零售流水可作替代信号，不与集团确认收入混算；同比增速变化不是金额环比。压货/去库存归因还需连接公司出货、应收返利、渠道库存、终端动销及后续补货。

## 事件驱动未来营收，再缩放
针对能改变判断的事件，交代基准、受影响业务、价格/销量机制、兑现条件、量级和时间；计划、产能、订单各有兑现条件，不能当成已实现收入或现金。优先使用有依据的区间或上限，缺精确数不放弃推理，但不编造概率。

```text
BusinessRevenue = RealizedVolume * RealizedPrice
DeltaGroupRevenue = Revenue_with_event - Revenue_without_event
GroupRevenueImpact_pct = AffectedRevenueShare * BusinessRevenueChange_pct
```
最后一式的占比用小数，变动率用百分数，仅适用于同一基准期间、同口径且其他业务不变的直接影响；不要重复乘已包含的兑现率。新业务估可实现增量，再除集团规模，不能从零基数算增速。拆分多事件时防止重复计算与业务蚕食；局部高增长不等于集团高增长。

成本、税费、资本开支、出售、融资与股本事件可直接传到利润、现金或每股结果，不强迫先经营收；收入、利润、现金及资产冲击使用相应分母。核心牌照、关键客户或交叉违约有集团传导时，不因直接占比小而遗漏。最终落到经常利润、营运资金、必要资本开支、股数、每股现金及分红，不把收入变化机械等同利润变化。

## 六维与资本纪律
| 维度 | 决定性问题 |
|---|---|
| 商业经济性 | 为什么客户付钱，维持利润需要多少资本与营运资金？ |
| 竞争地位 | 相对可比同行，客户留存、成本、议价或份额优势能否持续？ |
| 经营轨迹 | 长期与最新单季的真实方向、主因和持续性是什么？ |
| 现金质量 | 利润怎样转成经营现金及必要投资后的现金？ |
| 财务韧性 | 受限、归属、到期债务与已知支出后，还有多少可动用资金？ |
| 资本纪律 | 投入、持有现金、追加资本、税后退出和分配带来何种每股结果？ |

强净现金不代替好现金转换；应收、库存与应付变化需检查账龄、回款和时点，而非只看余额。成功退出后少赚利润先调整经营基数，不能否定全周期成功；资金未部署或缺IRR不是已发生毁损。混合资本纪律需有重要性相称的真实正负结果；检查低效扩张、融资摊薄、关联安排和兑现记录。正式确认、责任仍在当前体系且未实质隔离的重大诚信红线最高C；普通处罚按经济后果，传闻不当定案。

A+表示罕见持久的经济性、竞争与股东结果组合，A为明确优质，B为可成立但普通/混合，C为实质弱点，D为商业或股东利益根本受损，方向不能确定则暂不评级；综合重要性，不平均投票、不用价格或资料数量定级。

## 行业适配、反证与结论
同行匹配业务、价格带、客户、地域、渠道与资本模式，多元集团按利润池分析。周期企业看低谷和维护资本；银行看资产质量及监管资本，保险看承保/准备金/资本，地产区分开发与出租，不能强套一般FCF；软件看留存、资本化及股权摊薄，控股公司看上划权利，早期企业限定为有证据的商业判断。

用最强替代解释检验主线；继承历史事项但核对是否已解决、被替代或仍有效，不能把旧评级当证据。分别说明企业是否稳定、不实质衰退，以及分红是否有经营/财务/兑现支持；关键未知不通过，不因资料缺失自动把企业判差。确认非季节性失速/衰退时，将年度现金和分配情景传到两个价格参考；衰退研究值再便宜也不取消企业前提。
