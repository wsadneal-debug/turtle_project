# 统一核查与研究资源分流
仅批量候选/初筛使用；人工明确指定企业研究可以直接研究。先统一核查现金底座、年度现金、普通分红、回购及有金额期限的回报安排，不能先按未核现金估值拒绝。保留原值、更正值、正式来源、核查日期及真实期限，更正传到后续计算；不改来源原件。

初审先用原六年平坦覆盖与条件穿透回报分别比较：
```text
cash_research_ok = FlatCoverage6 >= 0.65
return_research_ok = ConditionalReturn_pct >= 0.65 * RequiredReturn_pct
route = research if cash_research_ok and return_research_ok else defer
strict_cash_ok = FlatCoverage6 >= 1.0
strict_return_ok = ConditionalReturn_pct >= RequiredReturn_pct
```
只有数值无法计算或核查调用失败才needs_input。最低营运资金、净现金未单独披露、无关回报或被拒更正只留警告；可计算不等于事实全核、经营稳定、分红持续或价格通过。一项超额不能补另一项不足。

初审有正式金额和期限的回购/综合回报安排，除明确激励/员工持股/股份奖励外可先作为条件口径；一般授权无金额期限不计，重叠只取综合计划。尚未执行、注销或资金支持未全核的条件记录不能沿用到最终资格；最终按回报参考核实。单个历史计划不够数据时不要自行补年化金额或续期。股东回报相当于市值5%只提供初筛线索，不能跳过两项计算。

无效、排除或不进公式的记录不触发重算并抹掉已有完整场景；确需更正而新现金字段空时，保留同价且分类完整的旧普通股息基准，说明局限，不虚构新值。报价刷新只重算原数据，不声称核查了新公告；既有研究不因报价变化重复深研。
