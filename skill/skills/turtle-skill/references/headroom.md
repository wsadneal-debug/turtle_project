# 两项容错与价格后裁决
沿最终已计算的现金底座K、六年真实路径总和、同价市值MV、同税费/组成/期限的GG及II反算；不另造年度路径或风险预测。

```text
CashSurplus = K + SumSixYearFCF - MV
AnnualReductionToBoundary = max(0, CashSurplus) / 6
CashDeclineCapacity_pct = 100 * min(1, max(0, CashSurplus / SumSixYearFCF))
ReturnDeclineCapacity_pct = 100 * max(0, 1 - II / GG)
```
现金百分比仅在六年FCF合计>0时计算，否则为null；GG<=0时回报余量为0，II缺失或<=0则该项不可计算。基准未达标显示未达标及差额，不能把负余量称可容忍损失。现金底座覆盖全部门槛时百分比上限100%，并说明仍依赖底座可用、不额外烧钱；不是永久保底。

现金余量是每年等额减少相对原平均年度现金的距离，不是复合衰退率。回报余量是原税后可持续分配整体等比例减少，不是普通分红必然下降。两者不能相加，更不是营收或股价跌幅。期限内承诺不自动永久化；默认六年路径中的负FCF直接扣减现金，不截零；旧兼容结果须标注未计真实消耗。

裁决前提供现金/金融资产/债务及归属构成、实际六年路径、原回报组成、修正依据和两项结果。主模型解释风险对经营、分红、资金与价格保护的影响；不只复述是否双达标、不重复扣风险、不把增长停止当作已经扣下行。不能估全部风险金额也可以按现有范围给结论，关键资金真实性或经营反证仍须处理。若裁决改假设，重算后交付。只刷新行情时保留旧反证检查日期，不复用旧价的“当前安全”断言。
