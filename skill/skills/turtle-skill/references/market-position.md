发现宿主本次暴露的已连接、已授权本地历史日线MCP，读真实参数规范后实际请求，不猜接口/端口、不装服务、不新增模型或订阅。核对市场、股份类别、代码、时区、365自然日窗口、复权和返回字段；按实际游标处理分页，第一页不是完整一年。无实际结果不称已取得。

失败仅在知道纠正方法或有另一已授权来源时有限重试，同一路径失败后至多再试一次。没有MCP不自动改网页搜行情；已提供的合格行情或用户明确指定替代来源可用，注明真实来源。MCP可访问外网，不因运行在本地就算离线；用户禁网时只用确认离线/缓存动作。查询不含私有材料。

日期去重排序，价格须正且有限，同日冲突先解决。只用截止日前数据，核对拆并股、除权、币种、来源覆盖和新鲜度；默认同口径可验证复权价格归一到最新尺度。仅收盘价时称收盘区间，不伪称盘中高低。原始未复权价格仅可另列有限观察，不能靠无大跳变证明已复权；关键冲突或跳变无法解释时不作可靠波动判断。

少于60个有效交易日跳过计算；60—199仅部分窗口；至少200且近一年覆盖与来源完整性可核验才称完整。数量不替代完整性，不补零/停牌日、不用月线冒充日线。新鲜度需对照实际最近交易时段，休市不等于过期；无法确认就标未知。无效或无法解释缺口不能跨接成正常单日日收益，可保留可靠位置而省略波动。

## 算式与分类
C_i为同尺度收盘共N条，P=C_N；H/L为窗口同口径高低（仅收盘则收盘极值）：
```text
RangePosition_pct = (P - L) / (H - L) * 100
ClosePercentile_pct = count(C_i <= P) / N * 100
r_i = ln(C_i / C_(i-1))
Vol_1y_pct = sample_stdev(r_i) * sqrt(252) * 100
Vol_20d_pct = sample_stdev(last_20_returns) * sqrt(252) * 100
VolRatio = Vol_20d_pct / Vol_1y_pct
Return_20d_pct = (C_N / C_(N-20) - 1) * 100
HighPosition = (ClosePercentile_pct >= 80) or (RangePosition_pct >= 85)
Warming = (VolRatio >= 1.25) and (Vol_20d_pct >= 30)
Violent = (Vol_20d_pct >= 60) or ((VolRatio >= 1.50) and (Vol_20d_pct >= 30))
```
样本标准差分母为样本数-1；20日收益需要21个连续有效收盘，252为方法约定。分位包含当前日，不是区间位置。H=L时位置不可定义，恒定序列分位100%无区分意义，不判高位；年波动0不算波动比。不得把不同尺度实时价混入历史收盘。

优先显示高位且剧烈、高位、剧烈、升温、未触发；已知条件真可确认警示，未知不能当假，全部相关条件可判断且均未触发才能称未触发。给真实来源/调用、观察日、复权、样本与覆盖、指标和部分/跳过原因，不附凭据。行情只管时机，不修改六维、现金回本或穿透回报，不触发订单。
