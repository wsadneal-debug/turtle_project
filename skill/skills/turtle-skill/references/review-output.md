# 复核与输出
交付前读取。默认同会话自查；有已授权独立上下文才做独立复核，交原始证据、截止日和首轮结果，不预设升降档。未实际调用第二模型不能声称独立验证；用户要求而宿主不支持时交首轮和待复核说明，不新增付费服务。

## 沿依赖链复核，不凑检查数量
回查承载结论的主体、日期、币种、单位、归属、原文和更正记录，区分支持、不支持及无法核实；能读相同本地原文可以核实内容，但不能宣称打开失败URL。删除关键错误证据后重审结论，不只删脚注。

既挑战乐观也纠正无依据保守：最新季度是否被累计数掩盖，季节性是否合理，事件是否真正推演并缩放到集团，是否遗漏直接现金路径或重复损失，旧事项进展是否更新，最强反证是否保留。现金/分红能力与两套价格情景应一致，不能正文衰退而公式增长。

重算必要公式和代入值，核对共享容量/税、负年份、重复回报计划、当年/全期资金及中间付款时点；行情核对真实调用、分页、复权与未知状态。只把实际做过的步骤写为已做，合成算例/静态检查不等于模型研究或真实MCP验证。不设“模型是否填满所有字段”的新增质量闸门。

## 默认交付
开头一句综合结论，紧接以下三个独立判断及组合结果：
- 企业前提：稳定/不成立/尚不能确认，并单独说明稳定分红的资金和兑现依据。
- 穿透回报：达到/未达到/未知；区间内依赖加点时明确条件，不默选有利门槛。
- 绝对估值：明显偏低/未显示明显低估/未知或不适用，注明标准、变体或下行上界。

仅企业及分红前提成立、两个价格条件同时成立才称策略内机会；衰退压力值通过不例外，缺资料不自动降级但不能算通过。质量专项则明确未评价格，不给机会资格结论。

随后用六维给核心判断、证据和信心，保留五年与最新单季关键比较、季节性、重大事件未来营收/集团缩放及每股现金后果；重要机会风险不凑数、不要求对称。价格展示主要中间量、原/新情景、方法分支与期限；行情独立给实际指标或跳过原因。列最强反证、可观察证伪条件及会改变结论的缺口。

声明报告期、研究截止日、价格日、资料覆盖、方法0.4.0与实际复核方式；引用紧邻主张，私有材料用附件名和页码，不外传。只交可验证依据与算式，不输出内部思考过程；机器可读仅按需，不要求专有JSON。更正后同步结论与全部受影响数值；写文件到用户任务目录，保留旧版，不写Skill本体。
