# 穿透回报：可分配现金，不是FCF收益率
默认独立重建；完整价格研究读取本篇。普通历史场景不把总现金加入每年容量，不把GG等同ROE、利润收益率或总投资收益。

## 固定口径与需求
O、D、B_buyback、MV使用同一经济权益、币种及量级；P、股数S、MV同日通常MV=P*S，多类别股份分别桥接，FX注明1单位报表币种兑换多少价格币种。记录原始期间及来源，所有输入有限，tau在[0,1]。
D取(估值日-365天,估值日]已实际支付且当时可知的普通现金股息，每股额d按事件去重、分类并处理拆并股：
```text
D = d * S
O0 = max(0, FCF_parent_annual)
```
D是当前股数下的年度基准，不必等于历史现金流量表支付额；解释股数/税/时间差。特别股息另列历史，单次已宣派未付另列前瞻，不加入历史TTM。单期DPS、利润支付率或多年平均不能静默替代事件窗口；分类或覆盖不全为部分/未知，不填零。

O0优先用最近完整年报可核对归母可分配现金，取不到才用上式FCF代理，说明租赁及归属桥接，不自动拿绝对回本F0替代。最新可靠可比归母年化FCF为L：O0>0且L/O0<60%时O=min(O0,max(0,L))；60%<=比例<85%只提示，>=85%不依此下修；O0=0不除。只有更新报告、Capex和归属可靠时触发，不凭新利润或投资现金流替代强算；不因最新增长自动提高年报容量。默认其他情况O=O0；取数不可靠则注明容量核验局限。

B_buyback只纳入已执行、注销效果核实的公司回购，排除库存股、激励、未执行授权及个人增持。作为持续组件需最近3*365天至少3个执行日、跨度>=180天、跨>=2日历年、最新一次<=120天且最近完整日历年度金额覆盖可靠：
```text
B_buyback = min(B_actual_365d, B_latest_complete_calendar_year)
```
回购365天及持续性窗口均含端点，与股息左开窗口不同。已核实但持续性不达标可取零，执行额另列；记录缺失则未知。新增发行、拆并股不得冒充回购注销。存在至少两年、金额期限明确且官方核验的计划，先读[承诺资金](return-commitments.md)，合格且当年/全期有支持才替换对应组件；不选最高结果、不与已执行额重叠。

## 共享容量与税
```text
D_alloc = min(max(D, 0), max(O, 0))
O_remaining = max(0, O - D_alloc)
B_alloc = min(max(B_buyback, 0), O_remaining)
ShareholderCash_net = D_alloc * (1 - tau) + B_alloc
GG = ShareholderCash_net / MV * 100
```
普通股息先占税前容量，回购用剩余；只给股息扣税，不能税后先释放容量或直接把未受约束回购/FCF收益率相加。O=0且必要输入已知时GG=0；未知不是0，不做0/0。方法税率情景A股0%、港股20%需明示，不宣称是用户实际税负；其他市场不继承，未知身份给明确税前/税后假设。

## 失速/衰退时重算分配能力
与绝对估值用一致的经营前景，但不把营收/FCF降幅机械等同减息。确认非季节性实质恶化后，独立估有依据的年度现金容量和普通股息/合格回购需求：
```text
O_forward = min(O, max(0, Supported_annual_owner_cash_scenario))
D_forward = Supported_annual_ordinary_dividend_scenario
B_forward = Supported_annual_qualified_buyback_scenario
GG_forward = Allocation(O_forward, D_forward, B_forward, tau) / MV * 100
```
Allocation即上一节税后共享分配，不能把容量调整后的GG再次机械打折。只在情景有依据时使用，不覆盖历史事件。固定金额且当前/剩余期资金仍能支持的计划按承诺参考重核，不机械削减；其容量是单列有期限的O_current，不把存量现金当永久年金。无法量化未来分配时保留历史GG作参考并注明未知/上界，不能冒充已核实前瞻或用未知抹掉已核实注销回购。

## 要求回报与价格档位
按估值日获取可追溯基准利率；以下为方法参数，利率为百分数、加点为百分点：
```text
II_A = China_10Y_government_bond_yield + 2
II_HK = EFFR + s, s in [1, 2]
KK = GG - II
ObservePrice = P * GG / II
HeavyPrice = P * GG / max(10, II)
StandardPrice = (ObservePrice + HeavyPrice) / 2
```
A股无额外固定最低值；其他市场需明确基准/加点。港股s未指定给区间：GG>=上限为全区间通过，GG<下限为不通过，中间取决于加点，不自选中点或默选下限。明确选下限才可按下限比较，不能说全区间通过。
价阶仅P、GG、II均正且门槛明确时可算；区间两端分别算并排序。标准价是价格中点，不是收益率中点；10表示10%。GG=0保留零结论，不给可用正价阶；未知或II<=0不硬算。档位是方法参考，不对应仓位或订单；冻结股数/现金/税/FX，刷新从原始情景重算。

分别输出历史实际、普通TTM、单次前瞻、合格承诺与可持续主结果及其期限。明示O/D/B及分配、税/FX、GG/II/KK、价格和观察日。两项价格条件须同时通过且企业/稳定分红前提成立才称策略内机会；质量专项或输入不足不假装通过。明确旧结果复现才读[兼容](compatibility.md)，不得混称默认路径等价。
