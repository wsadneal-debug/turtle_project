# 十方向60题（V2.3）

全模型共用尽调工作准则
1. 目的：识别明显机会和重大风险。本次是少量候选企业、人工启动的最终投资尽调，不是全面审计。判断价格是否大致明显便宜或偏贵、是否存在足以造成重大亏损的现实风险；不追求精确目标价或亏损概率。“一眼看懂”是研究后结论清楚，不是跳过调查。
2. 分工：只把本方向研究透。使用本次审核截止日前近3—5年及最新可得资料，调查决定性事实、变化与反证，复用可靠材料和计算，不重复整家公司研究。价格盲阶段只判断企业，最终由总审综合。历史窗口不改变未来分析期限。
3. 方法：抓住经济实质，不为精确而精确。围绕本方向的决定性事实与影响机制开展判断。能够定性判断的，不强求量化；需要估算的，采用足以支持结论的简单方法。只有提高精度可能改变判断时，才进一步细算。已披露事实和基本口径仍须准确，不能以粗估代替核实。
4. 取舍：按重大性处理缺口。说明影响机制，并尽量用有据的粗略百分比或范围交代相关规模占对应集团口径多少，明确分母、期间和归属，再判断是否足以改判；无法合理估计时说明原因，不硬编数字。相关规模占比不等于潜在损失占比或风险概率，缺少资料本身不证明存在重大风险。不影响方向的小差异注明后停止追查，可能改判且无法合理限定的才继续核实。
5. 判断：先给最有依据的判断，再限定。事实须真实；分析可采用有依据且明确标注的假设，不要求证明所有未来或消灭全部未知。局部未知只限制相关部分；综合者按影响机制与集团量级独立判断，不把局部尚无法确认直接升级为整体未知。合理估计稍变就翻转的机会不称明显低估；未发现明显低估不等于企业无法评价。
6. 底线：原文、币种、单位、期间、现金归属及重复计算必须分清。企业创造的现金、公司可分配的现金、投资者实收分红是不同问题。沿用宿主提供的策略定义；未提供的参数是接口缺口，不是企业风险。必要算术用已接入工具，结果不能冒充真实未来。
7. 交付：每题按指定类型给一个结论，再用2—4句讲决定性原因、依据及必要条件；缺口的规模和影响沿现有原因/限制交给综合者。需要等待时说明什么可取得证据或有据估计足以结束等待，不以全部资料齐全为前提。不重复背景、技术状态和免责声明，不写成长报告，不按总分或通过项数裁决。
研究充分，判断粗而有据；抓大问题，容忍不影响结论的小误差。既不为求确定编造，也不为避免犯错拒绝判断。


逐方向读取，不要求一次把全部题库注入每个任务。每题用本类结论选项，也可“尚无法确认/不适用”；后者说明原因。完整尽调保留原题号，专项仅答派发范围；不按数量或总分裁决。

## 01 盈利基础与需求

判断主要靠什么赚钱，生意更可能稳定、改善还是衰退。不要求精确拆分每项业务利润；结合主业规模、集团趋势和机制。稳定企业不需要高增长证明价值。

- **01.Q1** 主要利润来源是否基本清楚？（是 / 否 / 有条件成立）
- **01.Q2** 核心需求更可能改善、稳定还是恶化？（改善 / 稳定 / 恶化）
- **01.Q3** 最新变化是否更可能构成持续性恶化，而非短期波动？（是 / 否 / 有条件成立）
- **01.Q4** 主业承压时，其他业务或经营调整是否有大致足够的净抵补？（是 / 否 / 有条件成立）
- **01.Q5** 这些变化对集团持续现金的影响程度如何？（无 / 小幅 / 明显 / 严重）
- **01.Q6** 原有盈利和现金能力是否大体能够维持？（是 / 否 / 有条件成立）

## 02 竞争优势与持续性

判断赚钱能力靠什么保护、保护是否削弱。无宽护城河不自动不能投资；缺ROIC可用可比经营表现，重点查竞争变化，不凑指标。

- **02.Q1** 当前盈利能力是否有实际竞争优势支撑？（是 / 否 / 有条件成立）
- **02.Q2** 核心优势是在改善、稳定还是恶化？（改善 / 稳定 / 恶化）
- **02.Q3** 竞争、替代和价格战的威胁有多大？（低 / 中 / 高）
- **02.Q4** 维持竞争地位需要增加的投入是否明显侵蚀现金？（是 / 否 / 有条件成立）
- **02.Q5** 近年盈利、现金与投入表现是否支持优势持续？（是 / 否 / 有条件成立）
- **02.Q6** 合理不利条件下，主要盈利基础是否仍能维持？（是 / 否 / 有条件成立）

## 03 利润质量与股东现金

判断利润是否成为真实现金、现有回报是否大致有经营支撑。先查主要现金项目，再评估剩余差异；不为小额按金或结算追求全账对平，重大归属/受限/义务不能忽略。

- **03.Q1** 利润是否有经营现金支持？（是 / 否 / 有条件成立）
- **03.Q2** 主要必要支出是否已经考虑？（是 / 否 / 有条件成立）
- **03.Q3** 不可动用或不归属普通股东的现金是否重大？（是 / 否 / 有条件成立）
- **03.Q4** 是否存在影响结论的明显漏扣、重扣或口径错误？（是 / 否 / 有条件成立）
- **03.Q5** 现有普通分红规模是否大致可持续？（是 / 否 / 有条件成立）
- **03.Q6** 需要纠正的现金口径，对投资前提影响有多大？（无 / 小幅 / 明显 / 严重）

## 04 资产负债与生存压力

判断现实偿付或融资危机及股东损害。基准与融资收紧压力分开；不保证正常续贷，也不默认全部融资中断。无逐日表不妨碍有条件评价整体韧性。

- **04.Q1** 可用资金与主要刚性义务的量级是否匹配？（是 / 否 / 有条件成立）
- **04.Q2** 到期集中和再融资依赖程度如何？（低 / 中 / 高）
- **04.Q3** 合理经营压力下，企业是否大体能维持正常运营？（是 / 否 / 有条件成立）
- **04.Q4** 现金上划、担保或债权优先顺序是否带来重大风险？（是 / 否 / 有条件成立）
- **04.Q5** 被迫融资或资产处置可能造成多大损害？（无 / 小幅 / 明显 / 严重）
- **04.Q6** 整体财务缓冲是否足以应对主要风险？（是 / 否 / 有条件成立）

## 05 资本配置与投入纪律

判断赚来的钱是否合理使用、重大失败项目是否仍吞噬价值。聚焦重大投入和持续行为，不审计全部历史项目；缺项目IRR不等于不能判断。历史已消化损失与未来亏钱分开。

- **05.Q1** 近年主要资金去向是否与股东利益相容？（是 / 否 / 有条件成立）
- **05.Q2** 已识别的重要投资失败，其损害程度如何？（无 / 小幅 / 明显 / 严重）
- **05.Q3** 这些失败项目是否大体停止继续消耗资金？（是 / 否 / 有条件成立）
- **05.Q4** 未来重大承诺投入对股东现金的挤压程度如何？（无 / 小幅 / 明显 / 严重）
- **05.Q5** 扩张、并购或跨界行为的风险有多高？（低 / 中 / 高）
- **05.Q6** 未来资金使用纪律是否大体值得信任？（是 / 否 / 有条件成立）

## 06 治理、激励与回报兑现

判断管理层/控股股东是否可信、普通股东能否公平分享成果。主要记录与单项未核分开，不穷尽全部承诺或强求非公开合同；具体重大权益疑点才追查。无付款确认不推定已付或拖欠。

- **06.Q1** 是否发现重大且未实质解决的诚信问题？（是 / 否 / 有条件成立）
- **06.Q2** 激励安排与原有股东利益的冲突程度如何？（低 / 中 / 高）
- **06.Q3** 已核主要回报承诺是否总体兑现？（是 / 否 / 有条件成立）
- **06.Q4** 净稀释及回购用途对每股权益的影响程度如何？（无 / 小幅 / 明显 / 严重）
- **06.Q5** 重大关联安排是否存在损害普通股东的现实风险？（是 / 否 / 有条件成立）
- **06.Q6** 普通股东公平取得未来回报的前提是否大体成立？（是 / 否 / 有条件成立）

## 07A 独立估值与安全边际：报价前

不依赖乐观未来，先在价格盲阶段选一种适用简单方法，形成有据的基准/不利区间与主要敏感性。不要求未来假设已获财报证明；六年企业现金覆盖另列，不代替内在价值。精细调参才便宜的不称明显低估。

- **07.Q1** 估值口径是否符合企业经济实质？（是 / 否 / 有条件成立）
- **07.Q2** 基准价值区间能否大致界定？（是 / 否 / 有条件成立）
- **07.Q3** 合理不利情景对价值的影响程度如何？（无 / 小幅 / 明显 / 严重）
- **07.Q4** 结论对关键假设有多敏感？（低 / 中 / 高）

## 07B 独立估值与安全边际：报价后

解锁本次报价，用07A既有假设与实际计算判断大致贵贱和安全边际。有据的范围足够，不强求精确目标价；必要纠错列原因再重算，不迁就现价。与09分歧由总审按共同经济基础处理。

- **07.Q5** 现价属于明显低估、偏低估、合理还是偏贵？（明显低估 / 偏低估 / 合理 / 偏贵）
- **07.Q6** 合理不利情况下，是否仍有明显安全边际？（是 / 否 / 有条件成立）

## 08 大盘与行业估值环境

判断市场/行业大致便宜、合理或贵，以及环境风险。行业标签只找候选，按实际赚钱方式和盈利口径选择可比同业，不同业务分别比较；缺行业指数可用代表同业并限定范围，不以单股代表行业。异常或亏损PE不当低估，可用适用的其他指标及经营证据作粗而有据的判断，不强求精确分位或全行业结论，不用股价低代替估值低。获授权10年窗只作敏感性。

- **08.Q1** 大盘处于什么相对估值位置？（明显低估 / 偏低估 / 合理 / 偏贵）
- **08.Q2** 行业或有代表性的同业样本处于什么估值位置？（明显低估 / 偏低估 / 合理 / 偏贵）
- **08.Q3** 信用、融资及投资情绪的脆弱性有多高？（低 / 中 / 高）
- **08.Q4** 估值信号是否受到异常盈利或样本变化的明显影响？（是 / 否 / 有条件成立）
- **08.Q5** 市场转冷对本交易的影响主要是什么、程度多大？（无 / 小幅 / 明显 / 严重）
- **08.Q6** 当前环境是否提供额外的估值支持？（是 / 否 / 有条件成立）

## 09 交易回报与兑现条件

按参考价和明确资金假设判断回报吸引力与依赖。这是交易前分析，不要求已成交。个人仓位未知只限适合性；分红可合理预测，不冒充承诺。企业现金覆盖与持有人税后收款分别检验。

- **09.Q1** 参考买价与资金假设是否足以开展条件分析？（是 / 否 / 有条件成立）
- **09.Q2** 不发生估值修复，是否仍有合理的持有回报来源？（是 / 否 / 有条件成立）
- **09.Q3** 回报对增长、催化剂或乐观兑现的依赖程度如何？（低 / 中 / 高）
- **09.Q4** 税费、汇率、流动性和等待成本的主要影响有多大？（无 / 小幅 / 明显 / 严重）
- **09.Q5** 相对合理可得的替代选择，风险回报是否有吸引力？（是 / 否 / 有条件成立）
- **09.Q6** 现价是否值得进入人工投资决策？（是 / 否 / 有条件成立）

## 10 独立反方与重大亏损

站在反方找最现实的重大亏损路径并主动检验反证。不把未证明安全当重大风险，不强找致命问题；反论被削弱就撤回。暂跌、分红调整、永久价值损失分开。

- **10.Q1** 最有依据的重大亏损路径，其发生可能性大致如何？（低 / 中 / 高）
- **10.Q2** 一旦发生，对股东现金或权益的损害程度如何？（无 / 小幅 / 明显 / 严重）
- **10.Q3** 多个风险是否可能同时击穿同一保护？（是 / 否 / 有条件成立）
- **10.Q4** 低价是否更可能反映持续价值毁损？（是 / 否 / 有条件成立）
- **10.Q5** 最强反对论证是否经得起相反证据检验？（是 / 否 / 有条件成立）
- **10.Q6** 是否存在足以否决或暂缓本交易的决定性问题？（是 / 否 / 有条件成立）
