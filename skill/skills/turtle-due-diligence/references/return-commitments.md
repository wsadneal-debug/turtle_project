# 多年承诺：先核资格，再查当年和全期资金
仅存在可能计入的多年分红/注销回购承诺时加载。至少两年、正式核验、金额期限明确、尚有效且资金有支持；模糊派息率、一般授权和未注明用途回购不够。先保留普通场景，再按类别替换，不选最高GG。

## 剩余安排
记录计划类别、年额a、总额T、已执行F、结束日及剩余付款日程；旧计划更正/替代、已履行额去重。同时披露年额和总额时：
```text
Remaining = min(max(0, T - F), a * n)
a_remaining = min(a, Remaining)
```
n为一致观察期内剩余年数；仅总额不能擅自均分，只有明确均匀安排才折成年额。年度化基准不等于截止日后未付义务，当年已付款不重复计未来需求；无可靠日程就标年度化场景，不能声称精确剩余覆盖。混合“分红或回购”只有一份额度，保守归类并解释税。

## 持续现金：先定年度，再逐年置零
固定最近最多3个完整可比年度归母FCF原值，至少最近2年；保留负年，不跳过最新坏年，不用旧好年替换。2年要说明不足3年；已选年度缺数则F_rec未知。
```text
f_i_nonnegative = max(0, f_i)
F_rec = min(f_i_nonnegative for i = 1..m), m in {2, 3}
U = max(0, Available_net_cash - Capital_commitments_not_already_deducted)
O_current = max(0, FCF_parent_current, U)
TermCapacity = U + F_rec * n
```
40、-20、50得到F_rec=0，不是40。U须可动用、同股东权益口径并扣未扣过资本承诺，不是集团总现金；U只用一次，O_current不是FCF+U，已扣承诺不再扣。

## 全部需求与时点
只替换匹配类别：回购计划替换回购但保留普通股息，分红计划替换股息但保留独立核验回购；同一混合承诺不同时算两份。
```text
CurrentDemand = D_current + B_current
RemainingDemand = sum(Commitment_remaining_j) + sum(Retained_distribution_t for t = 1..n)
CurrentSupported = O_current >= CurrentDemand
TermSupported = TermCapacity >= RemainingDemand
```
n覆盖有效组件最晚结束日，每项按自身日程/期限计入；仅均匀且没有已支付部分时把保留年额乘n。保留组件未知则需求不完整，不能填零。还需核对每个中间付款时点，不可拿后期现金支付早到期义务。

全部输入已知才能称完整计算；可展示已知资金下限，下限足额可以说明支持依据，仅完整且不足才称不支持，其余未知。U单独已覆盖全部剩余需求可直接说明，不为凑公式虚构F_rec。持续FCF截零不消除真实未来烧钱，存在现金消耗、已知投资或融资压力时另做资金日程，不得仅据机械TermCapacity判支持。

## 与下行及主结果相接
经营实质失速/衰退时重核当前和全期资金，不只沿用历史F_rec；有支持的下行情景降低未来现金预测，未量化则说明不能确认的履约部分。固定金额承诺的金额不因营收下降机械削减，但“固定”不等于有资金保障，历史支持也不等于新情景继续支持。

只有资格、当年及全期资金和必要日程均有依据时，才在O_current内使用[穿透回报](lookthrough-return.md)的共享分配公式替换主结果的对应组件；不支持/未知则普通主结果保留、计划另列，不让未支持承诺抬高GG。有期限的计划注明到期边界，不能当永久稳定分红证明。列原始f_i、F_rec、U、n、当前/剩余需求、两项支持状态、现金消耗和付款时间约束。
