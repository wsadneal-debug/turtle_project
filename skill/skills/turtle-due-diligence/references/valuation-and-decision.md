# 价值、持有回报与五项裁决

## 三个独立问题
**原策略资格**：读[现金回本](absolute-valuation.md)、[穿透回报](lookthrough-return.md)及[容错](headroom.md)，按可核原输入复算。企业六年归母现金覆盖是净现金加六年FCF与市值比较，不扣投资者红利税、不加期末卖出价；不是六年股息必须回本。不完整数据只能给相应参考或未知，不能把65%资源线称买入线。

**独立价值**：07A根据经济实质选择一种适用的简单估值方法，列正常化现金/盈利、资本成本或倍数、维持投入、债务、归属、期末处理及假设来源。企业与权益口径先一致；自由现金流给企业的值需桥接净债务等，权益现金不能再重复扣债。现金资本化或总capex代理可作参考，缺维护开支/融资桥时不称严格EPV；经营必需资产重置值不是可分股东现金，净现金/出售收益不重复加。没有精确目标价仍可给有据区间与敏感性；行业专有方法不强套一般FCF。

**持有人回报**：按参考买价、持有股数、买卖费、实际币种/汇率假设、税负、股息权利与实际付款日、明确的期末出售假设逐笔列现金流。初始投入为负，股息与出售回款按真实或假设日期为正；不把公司回购现金当投资者直接收到的钱。税前股息只扣一次股息税，净额不得重复扣；公司FCF、回购和资本终值不扣同一红利税。除息前买入并已取得权利、卖出后才支付的股息仍按付款日列入；除息日及以后买入或除息前卖出不默认有权，特殊市场权利按适用规则核实。

对有完整日期的现金流可用宿主经过检验的XIRR/数值求解器；若存在多次正负号转换、无有效根或多根，说明限制，不凭空给唯一收益率。仅在金额/日期/费用/税费假设足够时称完整费用后持有回报；缺费用允许明确零费敏感性，不能默称完整。计算器仅覆盖双价格基本算术，不提供XIRR或完整独立估值，不能伪报已运行。

## 五项裁决
| 项目 | 结论选项 |
|---|---|
| 重大亏损风险 | 低 / 中 / 高 / 尚无法确认 |
| 企业估值 | 明显低估 / 偏低估 / 合理 / 偏贵 / 尚无法确认 |
| 大盘估值 | 同上，独立于企业结论 |
| 行业估值 | 同上，说明指数或可比样本范围 |
| 交易行动 | 进入人工买入决策 / 等待更低价 / 等待关键事实 / 否决本次交易 |

每项以决定性证据和集团量级说明理由。个人资金/仓位缺失只限制适合性，不等于无法研究企业。缺大盘/行业完整历史不自动否决公司；不能用单股低PE证明行业便宜，亏损PE和异常盈利须辨认。需要等待时说明哪份可取得证据或哪种有据估计能结束等待，而不是要求未来全部保证。

独立价值和持有回报可以与原策略资格结论不同，保留分歧及共同经济口径。基本面实质衰退或重大诚信问题不被低价抵销；没有数值验证仍可定性判断，但明确原价格条件尚未确认。研究裁决不是适合所有人的投资指令，不执行交易。
