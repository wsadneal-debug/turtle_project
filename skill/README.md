## 安装
将本包 `skills/` 内所需的完整目录放进宿主支持的Skill目录或按宿主导入方式加载；不要只复制SKILL.md。支持文件夹方式的宿主需要保留 `references/`、`scripts/` 和可选 `agents/`。中文/英文选一种，两个语言使用同名入口，避免重复安装。具体安装位置遵循宿主说明，本包不替用户改全局配置。

- [基础研究 turtle-skill](skills/turtle-skill/SKILL.md)：可单独安装；没有尽调目录也能完成基础分析。
- [可选尽调 turtle-due-diligence](skills/turtle-due-diligence/SKILL.md)：可单独安装；无需主系统、基础Skill或已有研究报告。

宿主不支持安装时，把所选入口和它需要的参考作为本次任务材料读取，不宣称安装成功。支持 `agents/openai.yaml` 的宿主将尽调设为显式调用；其他宿主仍须遵守入口的明确启用规则。安装完整包本身不启动研究。

## 使用示例
“使用 $turtle-skill 分析某公司，按V5.2.2给经营基准和两项价格结果；先询问我是否启用额外尽调。”

“只分析盈利基础，不评价格、不启用尽调。”——完成相应经营部分，不能输出完整买入资格。
