# 企业质量分析 Skill 0.4.0
从盈利基础、五年与最新单季、重大事件未来营收推演和集团缩放，追到每股现金与稳定分红，再同时检验穿透回报率和六年现金回本。低价不能补偿实质衰退，六维用于组织证据，不代替推理主线。

## 安装与使用
将完整的 `skills/enterprise-quality-analysis` 目录安装或加载到支持该格式的宿主；不要只复制SKILL.md。中文与英文包名称相同、方法完整一致，只安装一种，避免同名冲突；输出语言仍优先服从用户要求。无安装能力时，可将入口和所需参考作为任务材料，不等于已安装或自动触发。

示例请求：“使用此Skill分析指定企业；检查五年与最新单季，推演重要事件并缩放到集团，验证现金和稳定分红，再判断两项价格条件；缺失资料明确说明。”
仅附件研究可明确“不联网”；只要企业质量可明确“不评价格”；后者不会产生完整策略机会结论。

[入口](skills/enterprise-quality-analysis/SKILL.md)保留八步主线及何时读取参考的路由；五份常用参考负责证据、经营分析、绝对回本、穿透回报和复核。多年承诺、旧口径复现、行情、私有资料/公开版和合成算例按场景读取。无需其他Skill、数据库、Python、固定模型或私有项目文档；公式可以用宿主计算器、代码或可核对算术执行，没有工具就给依据及缺口，不伪称完成。
