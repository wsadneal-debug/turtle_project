# Turtle Investment Due Diligence: optional and standalone

This is the V2.3 investment-review method in the V5.2.2 distribution: ten directions/60 questions, synthesis, challenges, scenarios and adjudication. It is not relabeled EPV and does not require a prior base report. Install this directory alone; no other skill, database, model CLI or background system is needed. The host model performs research; bundled Python is optional arithmetic only.


Cash payback defaults to normalized historical averages plus operating adjustments, directly using six attributable annual cash values including negatives. Identify major current capex projects and payment stages in the first analysis. See [cash payback](references/absolute-valuation.md); legacy formulas are explicitly labeled references only.


## Activation
Off by default. Start only if this task explicitly requests investment due diligence/final review, invokes this skill, or already accepts the base skill's opt-in question. If unclear, ask: “Enable extra investment due diligence? It uses additional research time and model allowance; default is off.” Silence or refusal returns to base analysis/explanation without loading questions or dispatching agents. Risk or missing data is not consent. Do not ask twice after clear authorization.

After opt-in, confirm entity/cutoff, public/offline scope and permitted time/model allowance. Default to sequential work by the current conversation model. Opt-in does not authorize buying data, adding external model services or uploading attachments across services. Delegate bounded tasks only when the user requests multiple models and authorized capabilities exist. A requested specific investigation stays a partial review, never a claim of completing all 60 questions.

## Execution
1. Read [workflow](references/workflow.md) and [evidence](references/evidence.md). Assemble verifiable originals, decisive gaps and provenance of existing research. Without a system report, start with annual reports, comparable history and announcements. No database is needed. Without any originals, state the needed material rather than invent research.
2. Investigate the [ten-direction catalog](references/questions-v23.md). Complete 01–06 and 07A first, establishing operating/cash and independent-value assumptions; then unlock the quote for 07B, 08, 09 and 10. Sixty questions are not sixty calls or agents. Sequential single-model work is self-review; prior exposure to quotes prevents a strict price-blind claim.
3. Synthesize decisive disagreements, challenge only issues capable of changing the conclusion, and return original evidence, calculations and magnitudes. Build coherent baseline/adverse/severe scenarios. Do not combine mutually exclusive worst cases, demand numerical losses for every risk or fill research quotas.
4. Apply [value, holder return and decisions](references/valuation-and-decision.md), separating original strategy eligibility, independent value and investor receipts. Use host arithmetic or the [calculator](references/calculator.md). Missing parameters are not permission to invent system defaults. Actually recalculate changed assumptions.
5. Give five judgments: material-loss risk, company valuation, broad-market valuation, industry valuation and action, supported by the strongest countercase, conditions and evidence. Action is an input to human decisions, never a trade/publication/overwrite. Preserve V5.2.2 operating horizon, base direction, subjective decline leaning, magnitude, dividend consequences and one reversal condition.

## Delivery and stopping
Each question receives a conclusion, 2–4 sentences of decisive reasons and verifiable references. Explain material gaps through group magnitude and how they could change the decision. Lead with economic meaning; separate technical status. Retain full findings/challenges/scenarios and executed calculations; explain non-adoption of material evidence. No points, votes or unknown-rate scores. A precise target price is not required for a supported valuation judgment.

Missing data limits dependent conclusions. Representative peers can support a scoped comparison without a full industry series; missing personal constraints limits suitability only. Do not make every local unknown a global one. Label full/partial/stopped scope, actual model, data coverage, quote visibility and extra tools. One model playing multiple roles is not independent verification.

At the agreed budget/time limit or when no feasible useful evidence remains, preserve work, open issues and the stopping reason. No automatic expansion, provider switching, resumption or full restart. Do not poll progress with model calls. This package has no background runner and promises no unattended delivery. Write only to the user's task directory, preserving history. Follow [privacy](references/privacy.md) for private material and public versions.
