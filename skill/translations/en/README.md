# Enterprise Quality Analysis Skill 0.4.0
Follow earnings economics, five-year/latest-quarter trends, material-event revenue projections and group scaling to per-share cash and sustainable dividends, then test both look-through return and six-year cash payback. Cheapness cannot offset substantive decline; the six dimensions organize evidence rather than replace the reasoning chain.

## Install and use
Install/load the complete `skills/enterprise-quality-analysis` directory in a compatible host, not SKILL.md alone. Chinese and English packages share a name and complete method; install one to avoid name collisions. Explicit user language still takes priority. Without Skill installation, attach the entry and needed references as task material, not as a claim of installation/automatic triggering.

Example request: “Analyze the specified company with this Skill; examine five years/latest quarters, project material events and scale them to the group, verify cash and sustainable dividends, then assess both price conditions; identify missing evidence.”
For attachment-only research explicitly prohibit browsing; for quality-only work exclude prices. The latter does not establish a complete strategy opportunity.
